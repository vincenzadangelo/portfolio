# Vincenza D'Angelo — UX & Experience Designer

Portfolio bilingüe preparado para GitHub Pages.

- `/index.html`: versión principal en inglés
- `/es/index.html`: versión en castellano
- `/assets/`: imágenes compartidas por ambas versiones

## Publicación

En GitHub, abre `vincenzadangelo/portfolio`, sube el contenido de esta carpeta a la rama `main` y activa:

`Settings → Pages → Deploy from a branch → main → / (root)`

La URL prevista es:

`https://vincenzadangelo.github.io/portfolio/`

Versión española:

`https://vincenzadangelo.github.io/portfolio/es/`
